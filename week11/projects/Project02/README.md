# C Project Generator

> Simple script to create C projects with one command

## 📋 Description

This Bash script automatically creates a complete C project structure with:
- C source file (`main.c`)
- README.md file
- Makefile for easy compilation
- JSON metadata file
- Git repository initialization


##  Requirements

- **Operating System:** Linux / Unix / macOS
- **Compiler:** GCC
- **Tools:** Git, Make
