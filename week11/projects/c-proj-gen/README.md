# Bash script to generate a structured C project

it will generate a folder with the following structure:

```
project_name/
|-- bin/
|-- include/ {file1.h file2.h ...}
|-- src/ {file1.c file2.c ...}
|-- README.md

```

## Usage:

### Make the script executable:

```bash
chmod +x c_gen_project.sh
```

### Run the script:

```bash
./c_gen_project.sh
```
